Crear cuenta de cliente

El registro habilita la compra en línea y el acceso a promociones. Antes de grabar, el sistema comprueba con la API de mensajería que el correo exista y esté activo, porque es el canal por el que se envía la boleta.

Validación del correo (RF 11)

El front end sólo envía el correo al Web Service; la comprobación de existencia y estado la ejecuta la API de mensajería. Mientras responde, el botón queda bloqueado para evitar registros duplicados.

Para probar un rechazo del servicio, usa un correo del dominio @correo.inexistente o @noexiste.cl.

Registro en el local (RF 6)

El administrador puede registrar al cliente desde el mesón con este mismo formulario, disponible en el mantenedor de clientes. La validación del correo se aplica en ambos casos.

Validaciones aplicadas
  • RUN chileno con dígito verificador (módulo 11).
  • Formato de correo y existencia del buzón.
  • Teléfono móvil chileno de 9 dígitos.
  • Mayoría de edad según fecha de nacimiento.
  • Coincidencia y robustez de la contraseña.
  • Comuna, provincia y región obligatorias.
